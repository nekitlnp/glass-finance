# 🌟 Glass Finance — Liquid Glass Budget Planner

Премиальное и высокотехнологичное веб-приложение для учета личных финансов в стиле **Liquid Glass** с возможностью автоматического распределения доходов по категориям и двухсторонней синхронизацией с вашей личной **Google Таблицей**.

Приложение полностью готово к разворачиванию на **GitHub Pages** и работе на любых мобильных и десктопных устройствах как самостоятельное PWA (Progressive Web App).

---

## 🛠️ Быстрый старт: Интеграция с Google Таблицами

При первом запуске приложения вас встретит интерактивный пошаговый гид. Ниже приведена подробная инструкция для ручной настройки синхронизации:

### Шаг 1: Создание пустой таблицы
1. Откройте ваш [Google Диск](https://drive.google.com/) и создайте новую пустую Google Таблицу (или перейдите по адресу [sheets.new](https://sheets.new)).
2. Назовите её по вашему усмотрению (например, `Личный Бюджет — Glass Finance`).

### Шаг 2: Добавление скрипта интеграции
1. В верхнем меню таблицы перейдите в раздел **«Расширения» → «Apps Script»** (Extensions → Apps Script).
2. Полностью удалите весь стандартный шаблонный код (функцию `myFunction`) из открывшегося редактора.
3. Откройте файл `GoogleAppsScript.js` из корня этого репозитория, скопируйте его содержимое полностью и вставьте в редактор Apps Script.
4. Нажмите кнопку **«Сохранить проект»** (значок дискеты в верхней панели).

### Шаг 3: Развертывание Веб-Приложения
1. В правом верхнем углу нажмите синюю кнопку **«Начало развертывания» → «Новое развертывание»** (Deploy → New deployment).
2. Нажмите на значок шестеренки слева от «Выберите тип» и выберите **«Веб-приложение»** (Web app).
3. Заполните параметры настройки:
   - **Описание:** `Glass Finance API`
   - **Запуск от имени (Execute as):** `Вы (ваш email)` (Me)
   - **У кого есть доступ (Who has access):** **`Все`** (Anyone) — *это критически важно для корректной передачи запросов без дополнительных авторизаций!*
4. Нажмите кнопку **«Развернуть»** (Deploy).
5. Нажмите кнопку **«Предоставить доступ»** (Authorize access) и подтвердите разрешения для скрипта под вашим Google аккаунтом (нажмите *Advanced* → *Go to ... (unsafe)* → *Allow*).
6. Скопируйте сгенерированный **URL веб-приложения** (ссылка, которая всегда заканчивается на `/exec`).

### Шаг 4: Подключение ссылки в приложении
1. Откройте приложение **Glass Finance**.
2. Перейдите в **«Настройки»** (иконка шестеренки в правом верхнем углу).
3. В разделе **«Синхронизация Google Таблиц»** вставьте скопированную ссылку в поле ввода **SCRIPT_URL**.
4. Нажмите кнопку **«Сохранить»**. Настройка завершена!
5. Все ваши бюджеты, лимиты, доходы и расходы будут автоматически синхронизироваться в режиме реального времени.

## 💾 Локальный режим (Local Mode)

Если вы не укажете ссылку на Google Таблицу — приложение будет полноценно функционировать в автономном **локальном режиме**, безопасно сохраняя всю информацию напрямую в памяти вашего браузера (через `LocalStorage`).

Вы всегда сможете вернуться к настройке облачной синхронизации в настройках или нажав кнопку «Гайд» в окне настроек.

## 🚀 Деплой на GitHub Pages

Репозиторий полностью подготовлен для мгновенной публикации.

### Автоматический деплой через CLI (рекомендуется)
1. Установите все зависимости проекта в своем терминале:
   ```bash
   npm install
   ```
2. Подключите ваш проект к удаленному репозиторию на GitHub:
   ```bash
   git init
   git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
   git add .
   git commit -m "Initial commit with GitHub Pages setup"
   git branch -M main
   git push -u origin main
   ```
3. Запустите готовую команду для публикации в один клик:
   ```bash
   npm run deploy
   ```
   Эта команда автоматически соберет оптимизированный билд (Vite) и загрузит его в ветку `gh-pages` вашего репозитория.

4. В настройках вашего репозитория на GitHub перейдите во вкладку **Settings → Pages** и убедитесь, что в качестве источника (Build and deployment) указана ветка **`gh-pages`** (папка `/root`). Ваше приложение будет доступно онлайн!

## ✨ Основные возможности приложения

* **Liquid Glass дизайн:** Великолепные стеклянные панели, мягкие градиентные свечения и полностью оптимизированная контрастность.
* **OLED Black режим:** Экономия заряда батареи на AMOLED матрицах благодаря идеальному черному цвету.
* **Двуязычный интерфейс:** Поддержка Русского (RU) и Английского (EN) языков интерфейса.
* **Умное распределение доп. доходов:** Позволяет моментально делить любые сторонние заработки или премии поровну между выбранными категориями.
* **Перенос остатков (Rollover):** Автоматический расчет профицитов и долгов прошлых периодов.
* **Валютная гибкость:** Поддержка RUB (₽), USD ($), EUR (€), KZT (₸), BYN (Br) и UAH (₴) с автоматическим форматированием.
