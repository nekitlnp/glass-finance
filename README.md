# Glass Finance

Бюджет по категориям с синхронизацией в вашу Google Таблицу. Доход распределяется по категориям в процентах или суммах, остатки и перерасход переносятся на следующий месяц. Работает в браузере и ставится на телефон как приложение (PWA).

Приложение: https://nekitlnp.github.io/glass-finance/

## Возможности

- Бюджет категории задаётся долей дохода или суммой в месяц, второе считается само.
- Остатки и перерасход переносятся между месяцами. Процент трат считается от всего, что доступно в категории в этом месяце.
- Дополнительный доход можно разделить между выбранными категориями.
- Вкладка «Кэшбэк»: банки и категории на месяц, подсказка «чем платить», перенос категорий с прошлого месяца. Внутри справочник из 32 банков и 38 категорий, свои тоже можно вписать.
- Под названием приложения видно, синхронизированы ли данные с таблицей. Неотправленные изменения не теряются и досылаются сами.
- Порядок категорий в обзоре настраивается.
- Русский и английский интерфейс, тёмная и светлая тема, валюты RUB, USD, EUR, KZT, BYN, UAH.

Без Google Таблицы приложение тоже работает, но данные хранятся только в этом браузере.

## Как начать

1. Откройте приложение на телефоне и добавьте на главный экран.
   - iPhone: в Safari нажмите «Поделиться», потом «На экран „Домой“».
   - Android: в Chrome нажмите ⋮, потом «Установить приложение».
2. Создайте пустую Google Таблицу ([sheets.new](https://sheets.new)) и откройте «Расширения → Apps Script».
3. Замените весь код в редакторе содержимым файла [`GoogleAppsScript.js`](GoogleAppsScript.js) и сохраните.
4. Нажмите «Начать развертывание → Новое развертывание», выберите тип «Веб-приложение»:
   - «Запуск от имени» — «Я»;
   - «У кого есть доступ» — «Все».
5. Нажмите «Развернуть» и разрешите доступ: «Дополнительные настройки» → «Перейти на страницу…» → «Разрешить».
6. Скопируйте URL веб-приложения (заканчивается на `/exec`) и вставьте его на приветственном экране приложения или в настройках, в разделе синхронизации.

## Обновление до новой версии

Приложение на https://nekitlnp.github.io/glass-finance/ обновляется само. Обычно достаточно полностью закрыть его (смахнуть из списка открытых приложений) и открыть снова. GitHub Pages может до 10 минут отдавать старую версию — тогда подождите и перезапустите ещё раз.

### Перед обновлением

1. Откройте приложение с интернетом. Если недавно что-то вносили, дождитесь сообщения, что данные в Google Таблице обновлены. Новая версия при первом запуске берёт данные из таблицы, и всё, что до неё не дошло, пропадёт.
2. На всякий случай сделайте копию таблицы: «Файл → Создать копию».

### Если после перезапуска интерфейс старый

Значит, иконка ведёт не на github.io, а на старую копию приложения (например, адрес `….a.run.app`). Такая копия не обновляется. Чтобы это проверить, зажмите иконку и откройте её в браузере — увидите адрес.

1. Скопируйте ссылку на скрипт: в таблице «Расширения → Apps Script → Начать развертывание → Управление развертываниями», URL в блоке «Веб-приложение». Нужна именно ссылка `https://script.google.com/macros/s/…/exec`, ссылка на саму таблицу не подойдёт.
2. Удалите старую иконку. На iPhone вместе с ней обычно стираются настройки приложения: ссылка на таблицу, валюта, тема. Сами данные останутся в таблице.
3. Установите иконку заново с https://nekitlnp.github.io/glass-finance/ (как в разделе «Как начать», шаг 1).
4. Откройте её и вставьте ссылку на скрипт на приветственном экране — данные подтянутся из таблицы.

Старым адресом после этого не пользуйтесь. Старая версия при любом изменении отправляет в таблицу всю свою копию данных и может затереть новые записи.

### Обновление скрипта таблицы

Нужно, когда в описании версии сказано, что скрипт изменился. Последний раз так было, когда появился кэшбэк: без нового скрипта он хранится только на устройстве, и во вкладке «Кэшбэк» об этом есть заметка. Удобнее делать с компьютера.

1. Скопируйте новый код: кнопкой «Скопировать код скрипта» во вкладке «Кэшбэк» или из файла [`GoogleAppsScript.js`](GoogleAppsScript.js) (кнопка «Copy raw file»).
2. В таблице откройте «Расширения → Apps Script», замените весь старый код новым и сохраните.
3. Нажмите «Начать развертывание → Управление развертываниями», потом карандаш, выберите «Версия: Новая версия» и нажмите «Развернуть».

Не выбирайте «Новое развертывание»: оно создаёт новую ссылку, и её придётся заново вставлять в приложение.

Если вместо редактора открывается «Не удалось открыть файл», в браузере выполнен вход в несколько Google-аккаунтов. Откройте окно инкогнито и войдите только в аккаунт, которому принадлежит таблица.

### Проверка

- Под названием «Glass Finance» есть строка статуса синхронизации, внизу — вкладка «Кэшбэк».
- Внесите тестовую трату: статус сменится на «Синхронизация…», потом на «Синхронизировано · время», а строка появится на листе «Расходы». После этого удалите трату.
- После обновления скрипта в таблице появится лист «Кэшбэк».
- Если висит красная плашка, причина написана в ней после двоеточия. Кнопка «Повторить» отправляет изменения ещё раз.

## Для разработчиков

```bash
npm install
npm run dev     # локальный сервер на порту 3000
npm run build   # сборка в dist/
```

Публикация автоматическая: после попадания изменений в `main` workflow [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) собирает приложение и выкладывает его в ветку `gh-pages`. В пул-реквестах он только проверяет сборку. Вручную то же самое делает `npm run deploy`. В настройках репозитория (Settings → Pages) источником должна быть ветка `gh-pages`.
